# 整站模板制作体验增强：第一批

日期：2026-09-22。起点：main `d1d393e1`（E12 / E13 已合入）。
分支：`codex/template-usability`。独立开发，不修改 main、其他开发者的工作目录或机械/宠物演示站。

## 已实现

### 1. 栏目正文与跳转设置不一致的提示

- 富文本编辑页显示实际跳转目标，说明保存/发布正文不会取消跳转。
- 可视化编辑器从父栏目进入实际子页面时，在画布外展示同一提醒，不改既有真实编辑目标解析。
- 提供在新窗口打开父栏目跳转设置的链接，避免离开当前未保存的编辑页。仅拥有栏目管理权限的管理员看到该入口。
- 栏目设置提供“改为显示本页（保存栏目后生效）”。它只调整表单选择，仍需用户保存，不自动写数据库，也不删除子栏目。
- 无实际跳转目标的页面不显示确定性的跳转警告。

### 2. 配置生效来源

- 站点设置、主题、整站模板页显示可展开的覆盖提醒，仅超级管理员可见。
- 显示运行时覆盖、`config/overrides.php` 与数据库之间的优先级及后台保存值/当前生效值。
- 不自动修改覆盖文件，也不改变已有保存语义；明确说明保存和恢复默认值只改数据库。
- 为避免报告自身泄密，只明文展示站名、主题、颜色和显示模式；其他配置值统一遮蔽。HTML 一律转义，列表最多 100 项。
- 本批不是所有配置字段的逐项锁定界面；没有覆盖时维持现有页面。

### 3. 整站导出前检查

- 导出入口先检查，然后呈现报告与下载操作。下载请求会再次检查当前状态。
- 复用现有支持范围及数据关系校验；不满足条件时阻止导出，不放宽导入/新装保护。
- 检查公开导出快照中的导航、页脚、页面/产品正文及 Builder 按钮里，指向已知但未导出栏目的链接。
- 对已停用目标的链接列出来源、原链接和维护入口；用户可以修复后重检，或明确勾选后继续。程序不会自动删除/改写链接。
- 检查为只读，不访问网络、不执行主题 PHP。最多扫描 3000 处来源、列出 100 项问题，达到上限明确提示。
- 边界：不是全站爬虫；不验证外链、任意插件/自定义路由、主题 PHP 内嵌链接或全部内容详情 URL。未报告不等于验证通过。媒体及 ZIP 安全校验仍在导出过程中执行。

### 4. 补充：站点图标与动效设置

- 图标不再复用横版 LOGO 的大图展示：提供 16 / 32 / 48 像素预览、原图尺寸、非正方形/过小/加载失败提示。只提醒，不裁图、不拉伸、不阻止保存。
- 上传、媒体库选择、手填地址（输入防抖、失焦）与恢复默认值接入同一刷新入口；异步响应过期后不会恢复旧图。
- 不改机械站的品牌图片，不把横版 LOGO 自动裁成新图标；仍需站长选择独立方形标志。
- 动效设置补齐通用设置页需要的三语键；选项元数据缺失时从 defaults.php 补足，避免误显示为“是／否”。
- 保存仅接受 none / light / standard。历史非法值在表单里按前台策略显示标准；GET 不改库，保存时才写入管理员的选择。
- 这只是既有动效设置入口的修复，不代表下一批主题动态列表已接入统一动效。
