- 中、英、日三套内容包；区块内部使用可编辑的标题、文字、容器、卡片、图片和按钮，不使用整块 HTML。
- 复用随包本地示例图片，不引用机械站 uploads。缩略图是布局示意 SVG，不冒充实际页面截图。
- 静态预设的按钮/卡片默认指向 /contact.html，制作具体站点时确认栏目路径；示例图片和文案需替换，不代表真实业务资质。
- 旧 image-text 预设保留原样；新 story-split 是带明确图片比例、响应式顺序和分组入场的变体。
- 新动态预设使用 container + _query，不继续扩展已退役的 list-dynamic。

### 2. 动态卡片绑定

- CardElement 与现有标题/图片的处理方式一致：先解析动态值，再进行文本转义或 URL 白名单校验。
- 导入/保存时，只为明确声明了 dynamic_placeholder 的控件保留整串 {{loop.cover}} / {{loop.url}}。全局 UrlPolicy 没有放宽，不接受拼接属性、脚本协议或任意占位符豁免。
- 富文本描述中的动态值先转义，随后通过 HtmlPolicy；整卡片链接内仍移除嵌套链接。
- 图片和链接已在产品预设中绑定。改数据来源、数量等用既有容器循环面板（由 Pro 插件提供）；图片/链接字段继续保留现有编辑方式，不新增一个不完整的动态标签选择器。

### 3. 统一动效

- Container 与 Div 共用「子项依次入场」控件，新增速度和设备范围；默认为关闭，未开启时旧渲染输出不变。
- 静态网格与动态循环直接复用同一 data-stagger → YikaiMotion 路径；无需主题逐条挑选 CSS 选择器。
- 已单独配置动画的子项及含动画后代的子项不叠加分组动画；不动画分页、空态提示及编辑器缩放手柄。
- 无动效/访客减少动态效果：不播放；轻动效：只有 180ms 淡入、无错峰延迟和位移；标准：使用速度设置及有上限的错峰。复用现有站点策略，没有另造动画引擎。
- 编辑画布保持静态可选；已有明确的重播入口继续使用。脚本未加载时内容默认可见。
- 卡片悬停复用已有 lift / zoom，触屏、减少动态效果与全站强度继续遵循现有 CSS 策略。
- 适用边界：这是 Builder 容器和卡片的通用入口，不自动给任意第三方主题 HTML 添加动画。本轮不改写机械主题已有动效，也不做轮播、视差或自动视频的新增逻辑。
