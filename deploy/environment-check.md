# YikaiCMS 环境检测页

文件：`environment-check.php`。单文件、无外部资源、不依赖已安装的 CMS，可在安装前使用。

## 使用

- 将此 PHP 文件上传到待安装站点的根目录，通过浏览器打开 `/environment-check.php`。
- 当前开发目录也可直接访问 `/deploy/environment-check.php`。
- 支持中文、英文、日文，通过页面右上角切换。
- 检测完成后从服务器删除该文件，不作为长期公开的诊断接口。

## 检测范围

- PHP 最低 8.0；8.2 为推荐线，低于推荐线不阻止安装。
- 必需扩展、PDO 数据库驱动、Session，以及市场、更新、图片处理等使用的推荐扩展。
- 内存、文件上传开关、上传上限、POST 上限、执行时限和错误显示配置。
- 检测到 CMS 时，检查 config、uploads、storage 的存在及可写权限；不创建文件验证，也不修改权限。安装完成后的 config 只读加固可能被提示不可写，该项是安装期要求。
- 数据库实际版本、连接权限、伪静态、HTTPS、外部 API 连通性标记为待确认，不冒充检测通过。

项目内运行优先读取 `includes/RuntimeRequirements.php`；单独上传时使用本文件内的安装器基线快照。以后调整环境要求时，应同步单文件快照。

此页不读取 `config/config.php`，不输出 phpinfo、密钥、环境变量或服务器绝对路径，不连接数据库，不发出外部请求，不安装或修改站点。它不是完整安全审计。CLI 与网站 PHP 配置可能不同，请以浏览器访问目标服务器得到的结果为准。
