# v1.13.3 改动盘点（2026-07-30）

自 v1.13.2 起 50 个提交。本版无新增数据库迁移以外的结构变更；孤儿列迁移为老站补齐。

## 重要修复

### 文章 URL 根治（含 SEO 影响）
`contentUrl()` 对有别名的文章生成 `/{栏目别名}/{文章别名}.html`，而该形态被 .htaccess 的
单页通用规则吃掉（→ page.php），一律 404。前台各处此前各自硬编码 `/news/article/{id}.html`
绕开本函数，掩盖了问题。**影响面包括 sitemap 与 SEO 工坊的 llms.txt / 搜索引擎推送**——
提交给搜索引擎的可能是 404 地址。
- 文章统一走 `/news/article/{slug|id}.html`（按内容自身 type 判断，新闻子栏目 channel_type 是 list）
- 清掉 news.php 与首页栏目区块的硬编码特判，URL 只此一处定义
- ContentModel 的 getPrev/getNext/getRelated 补 `c.type` 列，否则详情页上下篇仍走坏分支

### 老站结构补齐（迁移 20260729_builder_columns）
install SQL 有、却从无配套迁移的 9 个"孤儿列"：contents 的 content_type / blocks_data /
sort_order / 案例四字段，products 的 material / scene。老站升级后构建器保存、产品保存、
案例保存各处报 Unknown column（cile.cn 1.9.2→1.13.2 升级首次暴露）。逐列判断，幂等。

### 产品分类聚合
ProductController 子栏目模式下用栏目 id 充当分类 id，但 ProductModel 只按 product_categories
树聚合——该表为空的迁移站（分类在 channels）父分类页只显示直挂产品。新增 categoryTreeIds()：
常规站行为不变，查无此行且命中 product 型栏目时回退栏目树。

### 其它
- PHP 8.0 + SQLite 相关：见 v1.13.2，本版补 CI 8.0/8.2 矩阵防回归
- news.php 分类高亮失效（重构后残留的孤儿变量 $categoryId，静默 bug）
- 首次点「折叠菜单」宽度不收（Alpine class 三元写法类残留）
- 手机端顶栏标题竖排、搜索图标与输入框重叠
- 升级配置卡曾落在死代码块中从未显示；saveNotifyLevel 被嵌套进另一函数

## 安全

- **管理员填写的 URL 统一协议白名单**：友情链接、社交账号、下载外链等最终进入 href 的字段
  此前只做 HTML 转义，javascript: / data: 伪协议仍可点击执行。友链渲染在前台页脚 = 面向
  全体访客的存储型 XSS；下载外链 = 低权角色存入、超管点击触发。新增 `safeUrl()`，输出侧
  （前台页脚 ×2、后台友链/社交/列表行内查看）与保存侧双重防护。

## 新功能

- **后台列表 WordPress 范式**（文章/产品/案例/下载/招聘）：标题下悬停行内操作
  （编辑｜复制｜移至回收站｜查看）、状态并入日期列、封面无图占位、底部「批量操作 ▾ + 应用」；
  新增 duplicate / batch_publish / batch_unpublish 后端动作。共享组件 admin/includes/list_ui.php
- **侧栏改版**：单开手风琴（同时只展开当前所在组）、分组图标、层级字号、组标题可点直达、
  折叠为图标栏（边界圆形把手 + 悬停飞出二级）
- **产品分类树首页版块**：数据源自动适配（product_categories 空时回退 product 型栏目树），
  可配标题/列数/显示数/搜索框
- **代码块复制按钮 + 语言标签**（前台，纯前端增强，存量文章自动生效）
- **升级配置**：控制台新版本提醒可设「全部 / 仅安全更新 / 关闭」，利用 releases.json 的 level 字段
- **插件管理**：已安装列表直接提示可升级并一键升级，不必先进插件市场
