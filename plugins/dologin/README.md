# 易登录（Easy Login）

YikaiCMS 原生插件，借鉴 [DoLogin Security](https://cn.wordpress.org/plugins/dologin/) 的一次性免密链接体验，独立实现，不包含 WordPress 插件代码。

## 使用

1. 要求 YikaiCMS v1.20.0 或更高版本、PHP 8.0 或更高版本。不提供 v1.19.9 兼容适配。v1.20.0 发布包须包含配套的 `admin_login_request` 登录钩子、`DoLoginLinkModel` 与 `20260914_dologin_links` 迁移；旧站应先升级 CMS，不能只复制插件目录。
2. 后台「插件管理」启用「易登录」，打开插件设置，首次点击「初始化易登录」。系统「数据库升级」及 CLI `migrate:run` 也包含同一迁移。
3. 超级管理员选择账号、有效期（15 分钟、1 小时、1 天、7 天）及备注，生成后立即复制链接。原始链接只在该响应中显示，不能从记录中恢复。
4. 接收者打开完整链接，点击「确认登录」。已绑定验证器的账号继续走系统双重验证。
5. 在最近 100 条记录中查看兑换时间/IP，或撤销尚未使用的链接。

## 登录防护与权限

- 插件按清单的最低 CMS 版本检查运行资格。v1.20.0 以下即使被旧安装器装入，也不会注册免密登录入口，设置页提示先升级 CMS；不会尝试调用新版模型。

- 复用系统 IP 登录失败限流及后台 IP 白名单；后台可调整现有失败次数、锁定时长。保持系统默认值，不自动覆盖设置。
- 仅超级管理员可生成、撤销链接及修改防护设置。演示模式禁止使用管理页。
- 登录身份沿用目标账号的当前权限。建议协作使用专用低权限账号；本插件不创建账号，不额外授予权限。
- 256 位随机凭证，数据库仅存基于站点 `ENCRYPT_KEY` 的 HMAC；凭证放在 URL fragment 中，不进入普通服务器访问日志。确认页使用本地资源、禁止缓存和 referrer，不通过 GET 消耗链接。
- 条件 UPDATE 原子消耗：过期、撤销和已兑换链接不能再次使用。目标账号密码、角色或双重验证绑定改变，会使尚未使用的链接失效。目标账号停用/删除、角色停用、签发人失去超级管理员资格时拒绝兑换。
- 链接过期或撤销仅影响尚未完成的兑换，不结束已建立的会话。已兑换不代表双重验证已完成。
- 禁用插件立即关闭入口；重新启用后尚未到期的旧链接仍可使用。需要永久作废时请先撤销。
- 记录含用户名、备注、时间与兑换 IP。禁用/删除插件不自动删除数据表；不向外部服务发送数据。

## 首版范围

后台管理员临时链接、撤销与兑换记录、现有限流设置入口、IP 白名单及 TOTP 兼容，中英日三语。未实现会员登录、Turnstile、GeoIP、IP 黑名单、二维码 SSO 或跨站登录。

## 验证

`php vendor/bin/phpunit --filter 'DoLoginLink|Migrator'`

使用隔离测试站完成 HTTP 登录、CSRF、权限、撤销、过期、重复使用、IP 白名单、限流、TOTP 与插件禁用验证；不在生产账号上生成测试链接。
